## Markdown form

The Markdown receipt is the compact review summary:

```md
# AgentProof receipt

- **Status:** PASS
- **Commit:** `96e440c08f9390dcaff0bce7985d29ee6dde5f58`
- **Config:** `sha256:1e5302987f79c47e1da5c1d68ed58d05f6ac56db30dc8f3468c99e853fc2a7c4`
- **Started:** 2026-10-10T04:41:31Z
- **Runner:** examples/export
- **AgentProof:** 0.1.0-dev

## Requirements

| Requirement    | State | Check | Detail |
| -------------- | ----- | ----- | ------ |
| unicode-export | PASS  | unit  | —      |
| csv-quoting    | PASS  | unit  | —      |

## Checks

| Check | Parser | Status | Exit | Duration (ms) |
| ----- | ------ | ------ | ---- | ------------- |
| unit  | go     | PASS   | 0    | 8547          |
```

## How to read it

- **Status** is the overall gate. `PASS` means every check passed *and* every
  requirement's evidence passed. Anything else is not a pass.
- **Commit** is the full SHA that was snapshotted and executed. It identifies
  exactly what ran.
- **Config** is the SHA-256 of the exact policy bytes. A whitespace-only change
  produces a different hash, so you always know which policy was applied.
- **Requirements** map your acceptance statements to their resulting
  [state](/guide/evidence).
- **Checks** show each command's parser, status, exit code and duration.

## A failing example

When a declared test is missing, the requirement becomes `UNVERIFIED` and the
gate fails closed:

```text
AgentProof FAIL
  commit a1b2c3d4e5f6...
  [PASS]       unicode-export
  [UNVERIFIED] error-handling   named test "pkg::TestErrors" not found in the evidence
```

This is the central behavior: **missing evidence never silently passes.** See
[detecting missing evidence](/learn/missing-evidence).

## The JSON form

`receipt.json` carries the full structured result — every check's command,
exit code, per-test outcomes, captured output and the trust warnings — for
automation and archival. See the [receipt format reference](/reference/receipt).
